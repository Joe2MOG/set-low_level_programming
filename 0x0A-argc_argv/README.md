# 0x0A. C - argc, argv

## Learning Objectives
- Understand the purpose of `argc` and `argv`
- Access and manipulate command line arguments
- Convert string arguments to integers
- Validate numeric input
- Print program name, argument count, and individual arguments

## Environment
- Ubuntu 20.04 LTS
- gcc flags: -Wall -Werror -Wextra -pedantic -std=gnu89
- Betty style

## Tasks
0. `0-whatsmyname.c` – print the program name
1. `1-args.c` – print the number of arguments
2. `2-args.c` – print all arguments, one per line
3. `3-mul.c` – multiply two numbers passed as arguments
4. `4-add.c` – add positive numbers passed as arguments
