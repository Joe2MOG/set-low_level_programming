# 0x0B. C - Preprocessor

## Learning Objectives
- Understand the role of the preprocessor in the compilation process
- Create and use object-like macros (`#define`)
- Create and use function-like macros
- Use predefined macros like `__FILE__`
- Write header files with include guards

## Tasks
0. `0-object_like_macro.h` – define `SIZE` as 1024
1. `1-pi.h` – define `PI` as 3.14159265359
2. `2-main.c` – print the name of the file it was compiled from
3. `3-function_like_macro.h` – define `ABS(x)` for absolute value
4. `4-sum.h` – define `SUM(x, y)` for addition

## Environment
- Ubuntu 20.04 LTS
- gcc flags: -Wall -Werror -Wextra -pedantic -std=gnu89
- Betty style
